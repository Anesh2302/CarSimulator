# Controller Setup

## Supported
- Keyboard
- Standard gamepads (Xbox/PS via browser Gamepad API)
- Touch controls

## Steering wheels
- Browser Gamepad API may expose wheel as gamepad.
- WebHID optional extension not implemented.
- Calibration screen shows live axes.
- Dead-zone, invert settings available.

## Limitations
- Force feedback not supported in browsers generally.
- Not all wheels expose identical axes; manual mapping required.
- No physical steering wheel hardware was tested in this environment.
